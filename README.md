##貢獻程度：
個人專案

##成果描述：
開發一款以Python撰寫的簡易兒童音樂遊戲，結合圖形介面與音效互動。相較一般音樂遊戲缺乏錄製功能，本專案加入「即時錄音並儲存創作」的功能，讓小朋友可以保留自己的音樂創作，提升遊戲的趣味性與教育價值。

##遇到的問題及處理方式：
執行的過程中，明明只需要一個視窗，卻有兩個視窗開啟，也無法正常顯示內容，發現Pygame和Tkinter會各自開啟視窗並且會互相阻塞。


這是因為 Pygame 和 Tkinter 各自有自己的事件循環，且可能會相互阻塞。

您可以通過以下幾種方式來解決這個問題：

避免同時使用 Tkinter 和 Pygame 的視窗：
由於 Pygame 和 Tkinter 都需要創建自己的視窗並管理事件循環，它們會競爭對視窗和事件的控制。在程式中，您只使用 Pygame 顯示遊戲界面，並且在需要顯示文件對話框或訊息框時，通過 Tkinter 來輔助處理，不讓 Tkinter 視窗影響遊戲流程。

隱藏 Tkinter 主視窗：
在您的程式中，您在使用 Tkinter 的 filedialog 和 messagebox 時，可以選擇隱藏 Tkinter 的主視窗，這樣 Tkinter 不會干擾 Pygame 的視窗。您在呼叫 Tk() 時，使用 root.withdraw() 隱藏了主視窗，這是非常好的做法。

更新畫面時處理時間延遲：
為了防止 Tkinter 的對話框阻塞 Pygame 的畫面更新，您可以在 pygame.mixer.music.pause() 或 pygame.mixer.stop() 等操作後，確保在顯示 Tkinter 視窗時不會造成太長時間的延遲。您已經適當地在進入文件選擇對話框後暫停音樂，並在播放結束後繼續進行。

總結來說，您使用了適當的方式來避免 Tkinter 視窗與 Pygame 視窗互相干擾。通過隱藏 Tkinter 主視窗並在需要時打開對話框，並且通過控制事件循環來避免視窗阻塞，成功解決了問題。
