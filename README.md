##貢獻程度：
個人專案

##成果描述：
開發一款以Python撰寫的簡易兒童音樂遊戲，結合圖形介面與音效互動。相較一般音樂遊戲缺乏錄製功能，本專案加入「即時錄音並儲存創作」的功能，讓小朋友可以保留自己的音樂創作，提升遊戲的趣味性與教育價值。

##遇到的問題及處理方式：
初期嘗試同時執行 Pygame 與 Tkinter，導致產生兩個視窗並互相阻塞，介面無法正常顯示與互動。深入了解兩者各自具備獨立事件迴圈與主線程需求後，決定以 Pygame 為主要畫面與互動平台，負責聲音播放與動畫視覺呈現，並將 Tkinter 作為輔助工具，用於實作選單、檔案儲存等 GUI 元件，透過流程控管與執行順序調整，有效整合兩者功能並達到預期效果。
